# Infinite Motion

Infinite Motion is the musical/experimental half of the project. It reuses the Laboratory's circular-pitch and motion primitives but does not claim its contradiction settings are canonical psychoacoustic demonstrations.

The QWERTY layout is A W S E D F T G Y H U J K. Web MIDI note input is progressive enhancement. The contradiction matrix can link all motion lanes or let pitch, tempo, stereo pan, distance, and spectrum oppose one another.
