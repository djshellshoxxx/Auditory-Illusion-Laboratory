# Auditory Illusion Laboratory Wiki

A browser-based psychoacoustic laboratory (React, TypeScript, Vite) with two parts:
the **Laboratory**, a set of research-grounded classic illusion stimuli, and **Infinite Motion**, an
experimental instrument that deliberately mixes cyclic pitch, rhythm, spatial and spectral cues.
